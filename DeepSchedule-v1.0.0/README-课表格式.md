# 课表格式（DeepSchedule）

一份课表工作簿 = 若干 sheet，**每个 sheet 一周**。

## 单元格布局

| 位置 | 内容 |
| --- | --- |
| 第 1 行 | `节次 ｜ 上课时间 ｜ 星期一 ｜ … ｜ 星期日` |
| 第 2 行起 | `第一节课` … `第十四节课`，一行一节，别插空行 |
| A 列 | 节次名，认「第X节课 / 第X节 / 数字」 |
| B 列 | 上课时间，写成 `08:30-09:15` |
| C–I 列 | 星期一至星期日 |

## 格里写什么

一格 = 一节课，最多三行（Excel 里按 `Alt+Enter` 换行）：

```
高等数学
鄞2-阶梯教室3
杨淑心
```

第二、三行（教室、教师）可以省略。

## sheet 名

写 `第3周` 或 `3` 都认；`Week 3` 也认。

## 也支持的其它来源

- 教务系统导出的 `.xls` / `.html`（「节次 × 星期」的大表，带 `5-19`、`6-18双` 这类注记）
- CSV：`星期,节次,课程,教室,教师,周次`
